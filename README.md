# ayushsingh0456.github.io

Portfolio of **Ayush Kumar Singh**, Business Analyst. Live at **https://ayushsingh0456.github.io**.

## What is here

| Page | What it shows |
|---|---|
| `index.html` | Profile, selected work, document library preview, SDLC process, experience and toolkit |
| `library.html` | 71 BA documents from three public case studies, filterable by project and type, opened in an in-page viewer |
| `case-studies/tendwell.html` | Home-care operations platform (fictional): BRD, SRS, stories, UAT, traceability |
| `case-studies/quartier.html` | Local-commerce ordering and appointments (fictional) |
| `case-studies/brasa.html` | Restaurant pickup ordering, iPad till and kitchen boards (fictional) |
| `case-studies/healthcare-ops-rebuild.html` | Confidential client rebuild, described without client material |
| `case-studies/mneme.html` | AI workspace concept and prototype |

The document viewer renders Markdown, CSV and OpenAPI files straight from the public case-study repositories, with Mermaid diagrams drawn in the browser:

- [us-home-care-operations-platform](https://github.com/ayushsingh0456/us-home-care-operations-platform)
- [local-commerce-booking-platform](https://github.com/ayushsingh0456/local-commerce-booking-platform)
- [multi-branch-restaurant-ordering-pos-platform](https://github.com/ayushsingh0456/multi-branch-restaurant-ordering-pos-platform)

## Tech

Static HTML, CSS and vanilla JavaScript, hosted on GitHub Pages. No build step is needed to serve it. [marked](https://marked.js.org), [Mermaid](https://mermaid.js.org) and [js-yaml](https://github.com/nodeca/js-yaml) load from jsDelivr only when a document is opened. Fonts: Instrument Serif, Inter and JetBrains Mono from Google Fonts.

## Note on content

Project names and data in these case studies are changed or synthetic. Client documents and real names stay confidential.
