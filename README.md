# ayushsingh0456.github.io

This is the source of the personal portfolio of **Ayush Kumar Singh**, a Business Analyst who works on healthcare and SaaS products.

Live site: https://ayushsingh0456.github.io

- Plain HTML, CSS and JavaScript, with no framework, build step or trackers.
- Light and dark themes that follow the system setting, plus a manual toggle.
- Accessible: semantic landmarks, a skip link, visible focus states, support for reduced motion, and WCAG AA colour contrast.
- Case studies are in `case-studies/`.
