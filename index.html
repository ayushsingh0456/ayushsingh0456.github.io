About

How I work.

I sit between clients, product and engineering, and make sure everyone is building the same thing.

Discovery

Client calls, gap analysis and competitor research, with recommendations that fit the client's budget, scope and market.

Requirements

BRDs, SRSs and user stories with clear acceptance criteria, plus architecture, user-flow and sequence diagrams.

Delivery

Scrum ceremonies, change requests, UAT and release coordination, through to handover of the codebase and documentation.

Business analysis

Requirements elicitation, stakeholder management, gap analysis, solution design, competitor research, MoSCoW prioritisation, impact analysis

Documentation

BRD, SRS, PRD, user stories (INVEST, Gherkin), change requests, SRS tracker / RTM, API documentation, incident reports, handover docs

Modelling & design
